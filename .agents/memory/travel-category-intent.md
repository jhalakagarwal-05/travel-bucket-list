---
name: Travel category intent
description: Product rationale for Wanderlist's travel categories.
---

Categories should reflect the user's mental model of travel so trips can be grouped meaningfully. The current category vocabulary is defined in the seed data; consult it rather than duplicating the names here.

**Why:** The user said they want categories that match how they think about travel.

**How to apply:** Preserve this user-centered intent when changing categories. Before retiring a category with assigned destinations, ask how those trips should be categorized if there is no obvious equivalent.
